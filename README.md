# Myntra Clone - FSD Project

## Project Overview

Myntra Clone is a frontend web development project inspired by the Myntra fashion shopping website.

The project is created to understand the basic concepts of HTML and CSS and to design a simple online shopping website.

## Project Objectives

- To learn website structure using HTML.
- To understand styling using CSS.
- To create multiple connected web pages.
- To practice responsive web design.
- To improve frontend development skills.

## Features

- Fashion shopping homepage
- Products page with product cards
- Shopping bag page
- Wishlist page
- Navigation between different pages
- Responsive layout for different screen sizes
- Product images, names, brands and prices

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the file using Live Server.
5. Explore the different pages using the navigation links.

## Limitations

This project is a frontend-only demonstration.

Features such as actual product searching, adding products dynamically, removing products, user login and online payment are not implemented.

## Conclusion

This project helped in understanding the fundamentals of frontend web development using HTML and CSS.

It also provided practical experience in creating multiple web pages, styling layouts and connecting pages through navigation links.
